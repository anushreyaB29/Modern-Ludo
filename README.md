# 🎲 Modern Ludo

A beautiful browser-based implementation of the classic **Ludo board game** built entirely with **HTML, CSS and JavaScript**.

Featuring animated gameplay, strategic AI opponents, customizable player setup, captures, home paths, dice animations, and a polished modern interface.

## Features

### 🎮 Gameplay
- Classic 4-player Ludo gameplay
- Supports 2–4 players
- Human and AI players
- Piece captures
- Safe cells
- Home stretches
- Win detection
- Extra turn on rolling a 6
- Automatic turn switching


### 🤖 Strategic AI
AI players prioritize:

- Capturing opponent pieces
- Bringing new pieces out on a roll of 6
- Advancing pieces already near home
- Moving pieces closer to home entry
- Intelligent move selection


### User Interface

- Modern dark-themed UI
- Animated dice rolling
- Piece highlighting
- Turn indicators
- Match logs
- Responsive board
- Confetti celebration on victory
- Smooth transitions and hover effects


```bash

```

or simply double-click the file.


## How to Play

1. Configure players

   - Enable or disable colors
   - Select Human or AI

2. Press **START GAME**

3. Roll the dice

4. Click a highlighted piece

5. Reach the center before everyone else


## Winning

The winner is the first player to move all four pieces into the home area.
